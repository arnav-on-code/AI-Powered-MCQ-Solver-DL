## Project Overview

This project is developed as part of the Smart MCQ Solver Challenge. The objective is to build an AI/ML-based system capable of predicting the top three most probable answers for multiple-choice questions (MCQs) containing a prompt and five answer options (A, B, C, D, E).

The project will explore Natural Language Processing (NLP), machine learning, information retrieval, and transformer-based techniques to improve answer ranking performance.
